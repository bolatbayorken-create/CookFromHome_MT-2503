# CookFromHome

Учебный сайт на HTML, CSS, JavaScript и jQuery. Для запуска откройте `index.html`. Для разработки удобно использовать Live Server в VS Code.

## Что сохраняется

Тема, продукты, план, покупки и выбранные рецепты хранятся в localStorage текущего браузера. Старые ключи сохранены. Для общего хранилища страниц используйте один локальный адрес; поведение `file://` зависит от браузера.

Контактные формы только проверяют поля, ничего не отправляют. Учебная авторизация реализована через localStorage; итоговый отчёт в эту версию не входит. Пример меню не является персональным планом питания.

## Регистрация, вход и профиль

Откройте Forms Sign Up. Регистрация сохраняет имя, email, телефон и тестовый пароль в `cfh-users`, затем переводит на Log In. Вход проверяет email и пароль, сохраняет текущий email в `cfh-session` и открывает Profile. После перезагрузки вход сохраняется. Log Out завершает сеанс, а попытка открыть профиль без входа возвращает на Log In.

Это локальная учебная имитация без сервера: пароль хранится в браузере. Используйте вымышленные данные и тестовый пароль.

Проверки находятся в `js/components/validation.js`, логика аккаунта в `js/pages/account.js`. Проверяются обязательные поля, email, имя от 2 символов, телефон из 10–15 цифр, пароль 8–64 символа с заглавной и строчной латинскими буквами и цифрой, повтор пароля, сообщение 10–500 символов. Ошибки показываются рядом с полями. Контактная форма и Tips используют те же проверки.
