# CookFromHome

Учебный сайт на HTML, CSS, JavaScript и jQuery. Для запуска откройте `index.html`. Для разработки удобно использовать Live Server в VS Code.

## Где что находится

- Девять HTML-файлов в корне — шесть основных страниц и Sign Up, Log In, Profile.
- `css/common.css` — палитра, текст, шапка, подвал, поля, кнопки, панели и общая область содержимого.
- `css/home.css` — главная страница.
- `css/recipes.css` — рецепты и фильтры.
- `css/planner.css` — план питания, покупки и Cook next.
- `css/pantry.css` — продукты, предложения и справка.
- `css/tips.css` — советы, замены ингредиентов и предложение темы.
- `css/forms.css` — контактная страница.
- `css/account.css` — регистрация, вход и профиль.
- `js/pages/` — поведение отдельных страниц.
- `js/components/` — формы, справка и сохранённые рецепты.
- `js/core/` — тема, localStorage и значки.
- `js/data/meal-plan.js` — пример недельного меню.
- `js/vendor/` — готовая библиотека jQuery; редактировать её не нужно.
- `icons/definitions.js` — контуры значков.
- `images/` — фотографии и фоны. Источники фотографий находятся в `images/recipes/sources.json`.

## Как редактировать

Тексты и рецепты меняются в HTML. При копировании карточки задайте уникальные `id`, `data-pick` и `aria-controls`. Для фотографии используйте имя `recipe-название.jpg` латиницей; у Lagman пока оставлена заглушка.

Каждая HTML-страница подключает сначала `common.css`, затем свой CSS. Общие стили не нужно копировать в файлы страниц. В CSS каждое свойство записано с новой строки, блоки разделены и снабжены короткими комментариями.

Кнопки используют общий класс `btn` и модификаторы, например `btn--sm` или `btn--quiet`. Поверхности блоков — общий класс `panel`. Не нужно писать одинаковое оформление заново на каждой странице.

Для значка достаточно `<span class="k-icon" data-icon="carrot" aria-hidden="true"></span>`. Скрипт заменит его на SVG. Длинные контуры в HTML не копируются.

Шапка и подвал остаются обычным HTML: при изменении навигации обновите все шесть страниц. Сборщика и настроек форматирования в проекте нет.

## Что сохраняется

Тема, продукты, план, покупки и выбранные рецепты хранятся в localStorage текущего браузера. Старые ключи сохранены. Для общего хранилища страниц используйте один локальный адрес; поведение `file://` зависит от браузера.

Контактные формы только проверяют поля, ничего не отправляют. Учебная авторизация реализована через localStorage; итоговый отчёт в эту версию не входит. Пример меню не является персональным планом питания.

## Регистрация, вход и профиль

Откройте Forms → Sign Up. Регистрация сохраняет имя, email, телефон и тестовый пароль в `cfh-users`, затем переводит на Log In. Вход проверяет email и пароль, сохраняет текущий email в `cfh-session` и открывает Profile. После перезагрузки вход сохраняется. Log Out завершает сеанс, а попытка открыть профиль без входа возвращает на Log In.

Это локальная учебная имитация без сервера: пароль хранится в браузере. Используйте вымышленные данные и тестовый пароль.

Проверки находятся в `js/components/validation.js`, логика аккаунта — в `js/pages/account.js`. Проверяются обязательные поля, email, имя от 2 символов, телефон из 10–15 цифр, пароль 8–64 символа с заглавной и строчной латинскими буквами и цифрой, повтор пароля, сообщение 10–500 символов. Ошибки показываются рядом с полями. Контактная форма и Tips используют те же проверки.
